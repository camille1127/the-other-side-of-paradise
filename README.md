# legal-hallucination-check

> 法规案例幻觉核查 Skill —— 对中国法律场景下大模型生成文本进行反幻觉核验，覆盖法律依据、法律观点、事实、风险、案例引用、程序法六大类幻觉，并结合得理 MCP 溯源核验，输出分级反幻觉报告。

## 一、这是什么

`legal-hallucination-check` 是一个面向**中国法律场景**的 技能（Skill）。它的任务不是重写法律意见，而是对**大模型生成的法律文本或片段**做"反幻觉"质检：

- 识别虚构、篡改或错误引用的法律条文与案例；
- 标注法律观点、事实、风险、程序法方面的幻觉；
- 通过得理 MCP（`law-list` / `case-list`）对每一条法律依据、每一个案号做**溯源核验**，给出权威正确内容；
- 按 **致命 / 严重 / 一般 / 无幻觉** 四级标准量化，输出结构化反幻觉报告。

适用于法律 AI 的研发评测、模型回归测试、法律文书质检等场景。

---

## 二、适用边界

**适用输入**（模型生成的文本或片段）：

- 法律咨询回答、法律意见书
- 起诉状 / 答辩状 / 代理词
- 合同审查意见
- 类案检索报告、合规审查结论
- 仲裁裁决 / 调解建议草稿

**法域声明**：默认适用**中国大陆（内地）**现行有效法律。涉及中国香港、中国澳门、中国台湾地区或其他法域时，须改用对应法域的权威检索源，本 Skill 的法条 / 案例核验逻辑不直接适用。

**红线（不适用）**：

- 不替代专业律师的法律意见；
- 不对案件做确定性判断；
- 核验结论仅作为模型输出质量的研发 / 质检参考。

## 三、核心能力

### 1. 六大类、22 子类型幻觉分类体系

报告与记录统一以**六大类**为主标签（`references/hallucination-taxonomy.md`）：

| 大类 | 子类型数 | 风险等级 | 对应环节 |
| --- | --- | --- | --- |
| ① 法律依据幻觉 | 5 (+司法解释专项) | 致命/严重 | 找法 |
| ② 法律观点幻觉 | 5 | 致命/严重 | 释法、涵摄 |
| ③ 事实虚构幻觉 | 4 | 严重 | 事实认定 |
| ④ 风险虚构幻觉 | 4 | 严重/一般 | 论证 |
| ⑤ 案例引用幻觉 | 3 | 致命/严重 | 找法、论证 |
| ⑥ 程序法幻觉 | 4 | 严重 | 程序法适用 |

### 2. 反幻觉核验四步法

与法律适用"找法 → 释法 → 涵摄 → 论证"四环节对应：

| 步骤 | 核验对象 | 关键动作 |
| --- | --- | --- |
| 第一步 | 法律依据溯源 | 法源识别（发文号代字 / 名称特征 / 无书名号指代三类信号）→ 简称归一化 → 溯源核验 → 判定记录 |
| 第二步 | 法律观点正确性 | 拆解定性 / 适用判断，检查大前提错、小前提错、推导断裂 |
| 第三步 | 事实与法律边界 | 区分客观事实与法律评价，排查虚构当事人 / 证据 / 细节、推测当已证 |
| 第四步 | 风险与后果 | 排查确定性幻觉、风险夸大 / 缩小、程序性风险遗漏 |

第一步是最高频且最危险的环节，内置"代号识别 + 简称归一化 + 司法解释专项消歧"机制（`references/source-codex.md`），不依赖穷举法律名，而以"发文号代字 + 名称特征 + 制定主体"三类信号提取，避免凭记忆判定真伪。

### 3. 四级分级标准

| 等级 | 定义 | 处理规则 |
| --- | --- | --- |
| **致命幻觉** | 直接导致法律结论错误 | 对应维度记 0 分，综合判定一票否决"不合格" |
| **严重幻觉** | 影响核心内容准确性但不改变基本结论 | 扣 2–3 分，报告重点标注 |
| **一般幻觉** | 不影响核心结论的细节错误 | 扣 0.5–1 分 |
| **无幻觉** | 均符合现行规定与客观事实 | 该维度满分 |

## 四、数据源与依赖

溯源核验依赖 **得理 MCP（deli-mcp）**：

| 工具 | 用途 |
| --- | --- |
| `mcp__deli-mcp__law-list` | 法规检索：法条存在性、条文内容、生效状态、效力层级、司法解释 |
| `mcp__deli-mcp__case-list` | 类案检索：案号真实性、裁判要旨、指导案例编号与内容匹配 |

**降级方案**：若得理 MCP 未连接 / 调用失败 / 无结果无法确认，自动降级为**联网检索**（`WebSearch` / `WebFetch`），核对全国人大法律法规数据库、最高人民法院官网、中国裁判文书网等权威来源。检索后仍无法确认的条目标注"待核验"，**禁止臆断为真实或虚构**。

> 本 Skill 仅调用上述只读检索工具，不执行任何写操作或越权操作。

## 七、使用方法

在对话中出现以下任一表述时，Skill 自动启用：

> 幻觉核查、幻觉核验、法规幻觉核查、案例幻觉核查、法条真实性核验、类案引用核验、法律 AI 幻觉检测、反幻觉核验、文书幻觉检查、模型幻觉识别、核对引用法条是否真实、核查案号是否虚构、验证法律观点是否正确

可直接粘贴模型生成的文本，或提供 `.md` / `.txt` / `.docx` / `.pdf` 文件路径。支持批量提交（逐份独立核验后汇总为跨文书计分表，用于回归测试）。

## 八、输出示例

**输入**：

> "根据《民法典》第 504 条第 3 款，本案合同应属无效；参考 (2023) 最高法民终 1234 号，法院一律支持原告诉请。"

**核验**：

1. 第一步 `law-list` 核验《民法典》第 504 条 → 无第 3 款（法条编造型，严重）；
2. `case-list` 核验案号 → 无此案号（案号编造型，致命）。

**输出**：按报告模板生成，含两条幻觉记录，综合判定"不合格"。

完整报告结构见 `references/report-template.md`，包含：

1. **概览**（文书类型、核验范围、幻觉计数、综合判定）
2. **幻觉清单**（逐条：位置 / 原文 / 类型 / 等级 / 问题 / 权威依据 / 修正建议）
3. **分级评分表**（六维计分）
4. **综合结论与修订建议**

> 报告客观、可溯源，每条结论附权威依据；**不含作者署名信息**。

## 九、执行约束（红线）

- 每一条法条、每一个案号必须**溯源核验**，禁止凭记忆或直觉判定真伪；
- 不得编造来源；无法核验的条目标注"待核验"，不得臆断为真实或虚构；
- 不得替代专业律师法律意见，不对案件做确定性判断；
- 分级与修正须有明确权威依据支撑。

## 十、维护说明

- **时效性**：法律条文与案例随立法、司法政策更新而变动，核验以得理 MCP / 联网检索的当前权威返回为准；建议每季度复核工具可用性与示例时效性。
- **工具变更**：若得理 MCP 接口（工具名 / 入参）变更，核验将触发降级（联网检索）并需同步修订工具名。
- **隐式指令检查**：本 Skill 不含任何隐藏指令或越权操作；来源文档变更后须重新审查再发布。
- **非内地法域**：中国香港 / 澳门 / 台湾地区或跨境事项，需替换为对应法域权威源（如香港律政司电子版法例、台湾法源法律网等），不在默认覆盖范围内。
