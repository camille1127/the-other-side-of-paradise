## 附：快速判定决策树

1. 引了法源（含司法解释）？→ 先用代字/名称特征/指代三类信号识别（见 source-codex），再做简称归一化。司法解释优先抓 `法释〔YYYY〕Y号`/`高检发释字〔〕` 代字以"年份+序号"唯一锚定；无代字则归一为"法律名+解释+（序号）"且**序号不可丢**，按序号实际条文核验（防解释三写成解释二），主体（最高法/最高检/两高）须归一，命中已废止/被替代映射→致命（详见代码本"七"）。得理mcp 搜不到、内容不符、已废止/被替代、层级错 → 法律依据幻觉（致命/严重）。
2. 引了案例/案号？→ 搜不到→联网检索仍无、要旨扭曲、编号错配 → 案例引用幻觉（致命/严重）。
3. 有定性/适用判断？→ 定性错、适用错、推导断 → 法律观点幻觉（致命/严重）。
4. 有事实陈述？→ 编造当事人/证据/细节、推测当已证 → 事实虚构幻觉（严重）。
5. 有结果/风险提示？→ 必胜断言、夸大/缩小、漏程序风险 → 风险虚构/程序法幻觉（严重/一般）。
6. 未命中任何信号且无法归一化？→ 标"待核验"，联网检索确认，禁止凭记忆判定。
7. 均通过？→ 无幻觉，该维度满分。
